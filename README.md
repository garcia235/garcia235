## 👋 Sobre mim

Sou Desenvolvedor Salesforce Pleno na **Taak**, atuando no desenvolvimento de soluções para
ambientes corporativos de média e alta complexidade. Trabalho com arquitetura de soluções,
integrações e evolução contínua de aplicações na plataforma Salesforce — utilizando **Apex**,
**Lightning Web Components (LWC)**, **Aura**, **Flows**, **SOQL** e integrações **REST** — sempre
buscando entregar sistemas escaláveis, performáticos e de fácil manutenção.

Além da implementação técnica, participo da definição de soluções junto às áreas de negócio:
levantamento de requisitos, desenho de arquitetura e estimativas técnicas. Gosto de entender o
problema antes de escrever código, buscando a solução mais adequada sob a perspectiva técnica e
de negócio.

- 🎓 Pós-graduando em **Arquitetura e Desenvolvimento Java** pela FIAP
- 🔭 Aprofundando conhecimentos em padrões de projeto, sistemas distribuídos, Serverless e programação reativa
- 🌱 Base sólida em engenharia de software, Java, Spring Boot e desenvolvimento backend
- ⚡ Experiência com Git, GitHub, CI/CD, code review, metodologias ágeis (Scrum) e React
